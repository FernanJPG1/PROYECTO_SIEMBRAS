# Auto Commit y Push a GitHub

Al completar cualquier tarea, corrección de errores, mejora o nueva funcionalidad y validar que los tests o compilación sean exitosos:
1. Realizar automáticamente `git add` de los archivos modificados o creados relevantes al cambio.
2. Realizar un `git commit` con un mensaje descriptivo y profesional siguiendo el formato convencional.
3. Ejecutar inmediatamente `git push origin main` para sincronizar las contribuciones con el repositorio remoto en GitHub de forma proactiva, sin requerir que el usuario lo solicite explícitamente.
